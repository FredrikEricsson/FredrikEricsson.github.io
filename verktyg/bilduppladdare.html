Sajtredigerare

Sidan nedan är sajten så som den ser ut live — klicka direkt på en rubrik, ett stycke eller en bildtext för att ändra texten, eller på en bild för att byta den. En av bildrutorna tar även emot ett kort videoklipp, som konverteras till mp4 direkt i webbläsaren. Längst ner i portfoliot kan du lägga till, redigera, flytta och ta bort projekt precis där de visas. Allt sparas automatiskt när du lämnar ett fält eller väljer en ny fil — välj bildmappen nedan först så sparas ändringarna direkt där istället för att laddas ner. Fungerar i Chrome och Edge, behöver ingen server — dubbelklicka bara på filen.

Den här webbläsaren stödjer inte direkt filskrivning till en mapp. Öppna sidan i Chrome eller Edge istället — då kan ändringarna sparas direkt i bilder-mappen utan extra steg.
Ingen mapp vald — ändringar laddas ner istället. Välj mappen bilder i sajtens repo för att spara direkt.

Klicka på text för att skriva om den, eller på en bild för att byta den.

När du är klar

  1. Öppna Terminal.
  2. Kör:
cd ~/Documents/FredrikEricsson.github.io
git add bilder
git commit -m "Uppdaterade sajttexten"
git push origin main
  1. GitHub Pages bygger om sajten på en minut eller två. Ladda om med Cmd+Shift+R om du inte ser ändringarna direkt — webbläsaren cachar gärna.
