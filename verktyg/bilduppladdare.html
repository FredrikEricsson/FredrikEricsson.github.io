Bilduppladdare

Välj bildmappen i sajtens repo (bilder), dra in fem foton nedan. Varje bild skalas ner och sparas direkt med rätt filnamn i mappen — sajten hittar dem automatiskt via index.html, ingen kodändring behövs. Du kan även skriva om texten under varje bild direkt här — den sparas i bilder/captions.js och sajten hämtar den automatiskt. En av rutorna tar även emot ett kort videoklipp — det komprimeras automatiskt till mp4 direkt i webbläsaren. Fungerar i Chrome och Edge. Öppna filen genom att dubbelklicka på den, den behöver ingen server.

Den här webbläsaren stödjer inte direkt filskrivning till en mapp. Öppna sidan i Chrome eller Edge istället — då kan bilderna sparas direkt i bilder-mappen utan extra steg.
Ingen mapp vald — välj mappen bilder i sajtens repo (skapa den om den inte redan finns).

När du är klar

  1. Öppna Terminal och gå till mappen där sajten ligger.
  2. Kör:
git add bilder
git commit -m "Lade till bilder"
git push origin main
  1. GitHub Pages bygger om sajten på en minut eller två. Ladda om med Cmd+Shift+R om du inte ser bilderna direkt — webbläsaren cachar gärna.
